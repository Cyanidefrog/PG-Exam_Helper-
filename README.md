# 考研刷卷助手（UniApp）

一个面向所有考研人的**本地刷卷打卡 + 错题本**小工具，基于 **HBuilderX + uni-app（Vue 3）** 开发，可同时发布为**微信小程序**和**安卓 App**。

## 功能

- **创建习题集**：选择学科（默认英语 / 数学 / 政治，也支持自定义学科）、设置卷子年份范围（如 2018 - 2024）。创建后，范围内**每一年就是一张卷子**。
- **刷卷记录**：打开一个习题集，会列出每一年的卷子；每张卷可以：
  - 选择**刷卷类型**：一刷 / 二刷 / 三刷（第几轮做这套卷）；
  - 右侧圆圈**打钩**，表示这张卷已经刷过，打完钩会记录完成日期；
  - 顶部有进度条，显示这个习题集已刷几卷。不需要精确到每道题。
- **错题本**：全部**手动录入**，支持：
  - 选择学科、填写年份、题号；
  - **写字**：在“题干 / 备注”里记录题目内容、错误原因或解题思路；
  - **拍照上传**：最多 3 张，自动压缩后存入本机；
  - 按学科筛选，点进去可看大图、编辑、删除。
- **数据全部在本地**：习题集、刷卷记录、错题、照片全部只保存在设备本地，不依赖任何服务器。

## 使用流程

1. 首页点「＋ 创建习题集」→ 选学科 + 年份范围 → 创建。
2. 首页点习题集卡片 → 进入「刷卷记录」→ 每做一张卷，选好一刷/二刷/三刷，然后打钩。
3. 做题遇到不会的题 → 错题本 → 右下角 ＋ → 填年份题号、写字、拍照 → 保存。
4. 错题本列表随时翻阅，点进去可看大图复习。

## 一、在 HBuilderX 中运行调试

1. 打开 **HBuilderX**（[下载地址](https://www.dcloud.io/hbuilderx.html)，建议用正式版）。
2. 菜单：**文件 → 导入 → 从本地目录导入**，选择本项目目录 `G:\PG-Exam_Helper\PG-Exam_Helper`。
3. 运行：
   - **浏览器预览**：菜单 **运行 → 运行到浏览器 → Chrome**。
   - **微信小程序**：菜单 **运行 → 运行到小程序模拟器 → 微信开发者工具**。
     - 首次使用需要先在 **运行 → 运行到小程序模拟器 → 小程序模拟器设置** 中配置微信开发者工具安装路径；
     - 并打开微信开发者工具：**设置 → 安全设置 → 开启“服务端口”**。
   - **手机真机预览**（安卓调试用）：手机连接电脑开启 USB 调试，菜单 **运行 → 运行到手机或模拟器**。

> 注意：如果之前已经运行过一次，改了 `pages.json` 后要**先点“停止”，再重新运行**，路由才会刷新。

## 二、上传到 GitHub

### 1. 先在 GitHub 创建仓库

- 打开 [github.com](https://github.com) → 右上角 **New repository**。
- 仓库名填写，例如 `pg-exam-helper`，**不要勾选** “Add a README file”（避免和本地冲突），创建后复制仓库地址（HTTPS 形式）。

### 2. 用命令行推送

打开 **PowerShell**（开始菜单搜索 PowerShell），依次执行：

```powershell
cd G:\PG-Exam_Helper\PG-Exam_Helper

git init
git add .
git commit -m "init: 考研刷卷助手"
git branch -M main
git remote add origin https://github.com/<你的GitHub用户名>/pg-exam-helper.git
git push -u origin main
```

- 把 `<你的GitHub用户名>` 换成自己的用户名。
- 推送时提示输入账号密码：用户名填 GitHub 用户名，密码**不是登录密码**，而是 **Personal Access Token（PAT）**。生成方法：GitHub → 头像 → **Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token**，权限勾选 `repo`，生成后复制保存。

### 3. 以后每次修改后上传

```powershell
git add .
git commit -m "更新说明"
git push
```

> 说明：项目根目录已有 `.gitignore`，已排除 `unpackage/`（编译产物）和 `node_modules/`，这些不会上传，可以放心。

## 三、打包成安卓 APK（云打包，最简单）

1. 注册并登录 **DCloud 账号**：HBuilderX 右上角头像处登录（云打包必须登录）。
2. 打开本项目，菜单：**发行 → 原生App-云打包**。
3. 在弹窗中：
   - **平台**：勾选 **Android**；
   - **证书**：测试用选 **“使用云端证书（测试）”**；正式发布再选“使用自有证书”（云打包页面可免费生成自己的证书）；
   - 填写**应用名称**（如：考研刷卷助手）、**包名**（如 `com.example.pgexamhelper`，测试可随意，正式上架后不可修改）；
   - 若提示配置图标/启动图，可以先不管，会使用默认图标（正式版建议在 `manifest.json` → App 图标配置 里上传 512×512 图标）。
4. 点击 **“打包”**，等待云端打包（约几分钟）。完成后弹出下载提示，下载得到的 `.apk` 文件即为安卓安装包。
5. 把 `.apk` 传到安卓手机安装：需在系统设置中允许“安装未知来源应用”；用测试证书打的包安装时可能提示风险，选择“继续安装”即可。
6. 想上架应用市场（华为、小米、应用宝等）需要：注册各平台开发者账号、准备正式签名证书、填写隐私政策等，流程以各平台为准。

> 补充：也可以做**离线打包**（需要 Android Studio 和 uni-app 原生工程），适合需要原生插件、上架某些特殊市场的情况，但流程较复杂，建议先用云打包跑通。

## 四、（可选）发布为微信小程序

1. 在 [微信公众平台](https://mp.weixin.qq.com) 注册小程序账号，获取 **AppID**。
2. 用 HBuilderX 打开项目，编辑 `manifest.json` → **微信小程序配置** → 填入 AppID（`mp-weixin.appid`）。
3. 菜单 **运行 → 运行到小程序模拟器 → 微信开发者工具**，确认功能正常。
4. 在微信开发者工具中点击 **上传**，填写版本号；然后到微信公众平台 → 版本管理 → 提交审核 → 审核通过后发布。

## 数据存储说明

- 结构化数据（习题集、刷卷记录、错题）通过 `uni.setStorageSync` 保存在本地缓存中，存储键为 `pg_exam_sets` / `pg_exam_records` / `pg_exam_wrongs`。
- 刷卷记录以「习题集 + 年份」为一条：记录刷卷类型（一刷/二刷/三刷）、是否已刷、完成时间。
- 错题照片先经 `uni.compressImage` 压缩，再通过 `uni.saveFile` 保存到本地文件系统（小程序保存在 `wx.env.USER_DATA_PATH` 下）。
- **注意**：所有数据只在本机，卸载小程序 / App 或清理缓存会删除本地数据；如需迁移，可后续增加“导出备份”功能。
